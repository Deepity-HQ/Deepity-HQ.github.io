Detailed Description

Storage type for the FP4 E2M1 format (see arXiv:2610.15933's W4A4E4 QAT setup). Converts to/from any arithmetic AccumT via Decode/EncodeFp4E2M1 (always through a float intermediate – the grid itself is only ever specified to float precision, so routing a double AccumT through it loses nothing beyond what the 4-bit grid already discards). The conversion constructor is explicit, since an implicit float/double -> 4-bit-grid narrowing happening by accident (rather than at a deliberate CPUBackendT decode/encode point) would be exactly the kind of silent precision bug this whole templating pass exists to make impossible to miss.
