Detailed Description

Templated counterpart to Backend.h's CreateBackend(), for FullPCNetworkT<T, AccumT>. Header-only (not CreateBackend()'s declaration + CreateBackend.cpp's definition split): a function template's definition has to be visible at every instantiation site anyway, so splitting it into a .cpp would just mean explicitly instantiating it there for every T/AccumT pair FullPCNetworkT supports – no simpler than defining it here once.
