template<typename AccumT>
void Deep::BindAdamStateT (size_t paramSize, std::vector< AccumT > &grad, std::vector< AccumT > &m, std::vector< AccumT > &v)
 Templated counterpart to BindAdamState(), for FullPCLayer<T, AccumT>: grad/m/v are AccumT-typed (the optimizer's own wider accumulator, see IComputeBackendT<T, AccumT>'s own doc comment), not T-typed like the layer's forward-path buffers – so, unlike those, they're never allocated from a layer's T-typed arena (a MemoryArenaT<T>'s Allocate() returns T*, which only happens to equal AccumT* when T==AccumT; for a genuinely different pair, e.g. Fp4E2M1Value's storage vs. its float accumulator, it's a flat type mismatch). Each one is instead a std::vector<AccumT> the layer owns directly. Valid for a host-resident backend only (every templated backend today); a future CUDABackendT<T, AccumT> would need its own device-resident accumulator storage instead of a host std::vector.
