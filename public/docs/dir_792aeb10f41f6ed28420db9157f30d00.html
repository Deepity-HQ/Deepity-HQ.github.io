 		ConvPCLayer.h
 Convolutional counterpart to DiscriminativePCLayer, precision- weighted, routed through IComputeBackend for GPU portability.
 		ConvPCLayerT.h
 Templated counterpart to ConvPCLayer, over a storage type T and an accumulator type AccumT. Every scratch buffer here (colBuffer, feedbackScratch, bottom_up_cols, colsRepacked, lgRepacked) stays T*, not AccumT*, same as SimpleConvPCLayerT.
 		DirectKPPCLayer.h
 Direct Kolen-Pollack predictive coding layer, routed through IComputeBackend. Bias updates go through AddBiasBroadcast()/SumRows(); biasGradScratch is a small (nextSize-length) accumulator SumRows alone can't provide, used by the SGD branch's bias update.
 		DirectKPPCLayerT.h
 Templated counterpart to DirectKPPCLayer, over a storage type T and an accumulator type AccumT. Does not inherit from Layer.
 		DiscriminativePCLayer.h
 Precision-weighted dense Predictive Coding layer, routed through IComputeBackend for GPU portability.
 		FullConvPCLayer.h
 Convolutional analog of FullPCLayer: muPC scaling, residual connections, DKP direct feedback, momentum settling, cross-entropy terminal loss, and ePC settling, each independently toggleable, off by default so plain defaults reproduce SimpleConvPCLayer exactly.
 		FullConvPCLayerT.h
 Templated counterpart to FullConvPCLayer, over a storage type T and an accumulator type AccumT. Every conv-specific scratch buffer here (colBuffer, feedbackScratch, bottom_up_cols, colsRepacked, lgRepacked, proj, projChannel, unpoolScratch, pooledMu, v, adjoint) stays T*, not AccumT*; the Adam/AdamW optimizer state (grad_W/m_W/v_W/..., grad_Psi/m_Psi/v_Psi) still follows the usual AccumT-accumulator convention.
 		FullPCLayer.h
 PC layer with DKP direct feedback, optional muPC scaling (a), and optional residual connections (useResidual), each off by default.
 		FullPCLayerT.h
 Templated counterpart to FullPCLayer, over a storage type T (the layer's own beliefs/errors/weights/activations) and an accumulator type AccumT (the Adam/AdamW optimizer's gradient/ moment state).
 		GaussSeidelPCLayer.h
 A PC layer whose settling dynamics follow a Gauss-Seidel (sequential-sweep) update, not the Jacobi (fully-synchronous) update SimplePCLayer uses. Routed through IComputeBackend for GPU portability; feedback goes through the independent matrix E rather than W (see below).
 		GaussSeidelPCLayerT.h
 Templated counterpart to GaussSeidelPCLayer, over a storage type T and an accumulator type AccumT. See GaussSeidelPCLayer.h's own class comment for the required three-sweep (UpdateState/ ComputePrediction/ComputeError) calling order, unchanged here. Does not inherit from Layer.

 		SimpleConvPCLayerT.h

 		SimplePCLayer.h
