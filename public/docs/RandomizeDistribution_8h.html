Detailed Description

Shared "name(a,b)" distribution-string parser for every PC layer's RandomizeWeights(rng, distribution) overload, generalizing the parsing SimplePCLayer::RandomizeWeights() originally did inline. One copy instead of one per layer file, so e.g. "normal"/"uniform" spelling and the malformed-string fallback behavior can't drift between layers.
