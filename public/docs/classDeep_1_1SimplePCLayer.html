◆ CalculateState() [2/2]

float Deep::SimplePCLayer::CalculateState ( bool needEnergy = true)
noexcept

Calculates the total network energy state, and this layer's outgoing prediction (mu).

\[E = \sum_l 1/2 ||z^{(l)} - \mu^{(l)}||^2 \]

mu = W @ phi(z) + b: activation applied to z before the linear transform (see this class's file comment on this convention). When SetCrossEntropy() is enabled, this layer's own term in E uses softmax cross-entropy against layerBelow's mu instead of the plain Gaussian form above – see ComputeSoftmaxCrossEntropyErrorAndEnergy.

Parameters
needEnergyAsks for energy
Returns
This layer's energy contribution at the current state, if asked for.

◆ UpdateState()

void Deep::SimplePCLayer::UpdateState ( )
overridevirtualnoexcept

Computes the state derivatives for inference.

\[\frac{dz^{(l)}}{dt} = -e^{(l)} + \sigma'(z^{(l)}) \odot (W^{(l-1)})^T e^{(l-1)} \]

The derivative multiply applies AFTER the W transform, using f'(z) (this layer's own state derivative) – not before projecting, and not f'(mu): under mu=W@phi(z)+b, the nonlinearity lives on z, so that's where its derivative applies too.
