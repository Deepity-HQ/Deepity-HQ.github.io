88 // derivScratch/feedbackError/proj/feedbackScratch below are AccumT*,
89 // not T*, unlike every buffer above -- a real, deliberate asymmetry,
90 // not an inconsistency with the rest of this class. They're pure
91 // transient compute (never read back by a caller, never persisted),
92 // and their natural magnitude -- an activation derivative, and
93 // everything downstream of multiplying it into an error signal -- can
94 // fall entirely below a lossy T's coarsest resolution (sigmoid's
95 // derivative maxes out at 0.25, under Fp4E2M1Value's smallest nonzero
96 // magnitude of 0.5). Routing them through T even transiently rounds
97 // them to exactly zero and silently breaks every gradient that flows
98 // through them, for every activation whose derivative range
99 // undershoots the grid -- found via this plan's own MNIST validation
100 // pass, not anticipated at design time. See
