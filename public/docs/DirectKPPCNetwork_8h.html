Detailed Description

Orchestrates DirectKPPCLayer's Direct Kolen-Pollack predictive coding (DKP-PC) phases, in order:

  1. Forward initialization: clamp input, forward-project every hidden layer's z from current weights, clamp the target, then CalculateState() on the terminal layer alone to produce a real, non-zero epsilon_L. Every other layer's error stays zero here.
  2. Direct feedback alignment update: DirectFeedbackUpdate() on every non-terminal layer, perturbing W using epsilon_L (via terminalLayer) and the layer above's Psi, before settling begins.
  3. Inference phase: ordinary PC settling (CalculateState() + UpdateState() across every layer) for inferenceSteps steps.
  4. Learning phase: UpdateWeights() on every non-terminal layer, updating both W (from the settled state) and Psi (from the settled state and epsilon_L).

Routed through IComputeBackend; device defaults to DEVICE_CPU.
