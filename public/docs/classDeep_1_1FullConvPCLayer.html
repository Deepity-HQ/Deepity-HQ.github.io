std::map< std::string, TensorDescriptor > Deep::FullConvPCLayer::GetStateDict ( ) const
overridevirtual

Returns this layer's named, shaped weight/bias tensors, for ModelIO's save/load. Empty by default; override to expose a layer's actual parameters.

Warning
For a layer whose parameters live in device memory (e.g. under a CUDA backend), the returned pointers are only safe for ModelIO to read/write directly if SyncStateDictFromDevice() was called first (for a save) or SyncStateDictToDevice() is called afterward (for a load) – see those methods.
Returns
{} if outChannels == 0 (this layer owns no W/b/Psi). Otherwise W, b, Psi, and each of their Adam moments (m_W, v_W, m_b, v_b, m_Psi, v_Psi), pointing at this layer's host staging buffers (see EnsureStateDictStaging()) – always safe for ModelIO to read or write directly, regardless of backend.

const float * Deep::FullConvPCLayer::UnpoolError ( const float * pooledError)
protectednoexcept

When HasPooling(), scatters pooledError (sized poolOutHeight*poolOutWidth, this layer's own output resolution) into unpoolScratch at conv-native resolution and returns that; otherwise returns pooledError unchanged. Every call site that reads a neighboring layer's error/adjoint needs this before combining it with mu, which stays at conv-native resolution regardless of pooling.
