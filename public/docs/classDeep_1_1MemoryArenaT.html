Detailed Description

template<typename T>
class Deep::MemoryArenaT< T >

A 64-byte-aligned bump-pointer allocator over a single contiguous block of host memory, generic over the element type T it hands out. Every chunk handed out via Allocate() is itself 64-byte aligned, satisfying this codebase's strict alignment requirement for AVX2/AVX-512 loads.

Template Parameters
TElement type this arena allocates. MemoryArena (see the alias below) is MemoryArenaT<float>, preserving every existing non-templated caller's behavior exactly; new templated code (FullPCLayer<T>/FullPCNetwork<T>) uses MemoryArenaT<T> directly.

Allocates a single 64-byte-aligned buffer large enough to hold total_elements elements of type T, rounded up to the nearest 64-byte boundary.

Parameters
total_elementsTotal number of elements this arena can hand out across all future Allocate() calls combined.
use_huge_pagesOpt-in, best-effort request for huge-page-backed memory (see HugePageAllocPortable() for the platform-specific caveats). Defaults to false, preserving existing behavior exactly for anyone not explicitly opting in. Falls back safely to the standard aligned allocator if the request isn't honored, this never causes a hard failure on its own.
Exceptions
std::bad_allocif the underlying allocation fails (including the fallback path, if huge pages were requested but unavailable).

Allocates a 64-byte aligned chunk of num_elements elements of type T from the arena.

Parameters
num_elementsNumber of elements to allocate from the arena. The actual reservation is rounded up to the nearest 64-byte boundary, so the returned chunk may have more usable capacity than requested.
Returns
Pointer to the start of the allocated chunk, valid for the lifetime of this MemoryArenaT. 64-byte aligned.
Exceptions
std::runtime_errorif the requested allocation would exceed the arena's total capacity.
Warning
Individual chunks are never freed independently; the entire arena is released at once in the destructor.
