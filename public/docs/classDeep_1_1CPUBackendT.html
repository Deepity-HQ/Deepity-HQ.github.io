Detailed Description

template<typename T, typename AccumT = T>
class Deep::CPUBackendT< T, AccumT >

Templated CPU implementation of IComputeBackendT<T, AccumT>, used by templated layers/networks (FullPCLayerT, SimplePCLayerT, GaussSeidelPCLayerT, DirectKPPCLayerT, and the conv family). Separate from, and not a drop-in replacement for, the non-templated CPUBackend, which DiscriminativePCLayer and non-templated layers still use.

For T=float, GEMM/activation/elementwise methods dispatch through the same BLAS/Highway kernels as CPUBackend. For other T (double, quantized formats), the same methods fall back to a plain scalar loop.

Every "Try*" fused-path method (TryFusedMatMul, TryFusedConv*, ...) always returns false: no fused CPU implementation is available through this backend, so callers must use the corresponding unfused sequence. FusedStateUpdate(), FusedStateUpdateMomentum(), FusedActivationDerivativeMultiply(), and FusedActivationDerivativeMultiplyFromPreact() are not implemented and throw if called; see each method's own exception message.
