Deep::CPUBackendT< T, AccumT > Class Template Reference

Templated CPU implementation of IComputeBackendT<T, AccumT>, used exclusively by the new templated FullPCLayer<T>/FullPCNetwork<T> path (see QuantFormat.h and the "Templating Deepity's layers/networks over a numeric type" plan). Deliberately NOT used by, and NOT a replacement for, the existing non-templated CPUBackend – every other layer (SimplePCLayer, DirectKPPCLayer, GaussSeidelPCLayer, the conv family) keeps using CPUBackend exactly as before. Detailed Description

template<typename T, typename AccumT = T>
class Deep::CPUBackendT< T, AccumT >

Templated CPU implementation of IComputeBackendT<T, AccumT>, used exclusively by the new templated FullPCLayer<T>/FullPCNetwork<T> path (see QuantFormat.h and the "Templating Deepity's layers/networks over a numeric type" plan). Deliberately NOT used by, and NOT a replacement for, the existing non-templated CPUBackend – every other layer (SimplePCLayer, DirectKPPCLayer, GaussSeidelPCLayer, the conv family) keeps using CPUBackend exactly as before.

Only implements the ~20 IComputeBackendT methods FullPCLayer<T>/ FullPCNetwork<T> actually call (MatMul, the elementwise/activation ops, Adam, graph-capture no-ops, ...) with real per-T behavior: for T=float, every one of those reuses the EXACT SAME dispatch this project's existing CPUBackend uses (cblas_sgemm, the Highway- dispatched kernels in CPUBackendHighway.*), so FullPCLayer<float>'s output is bit-exact against the pre-templating FullPCLayer – see this project's quantization plan's verification gate #1. For any other T (double, and eventually the quantized formats), those same methods fall back to a plain, correct, non-Highway-vectorized scalar loop; genuinely vectorizing them (via Highway's own T-generic hn::ScalableTag<T> kernels) is flagged as a deliberate, documented follow-up, not attempted in this pass.

Every OTHER IComputeBackendT method – the "Try*" fused paths (oneDNN/libxsmm/Halide/cuDNN-flavored; FullPCLayer never calls any of them, only SimplePCLayer/the conv family do) and the conv/ precision-weighted-layer-only ops (Im2Col, Col2Im, MaxPool2D*, RepackForBatchedGemm, AddBiasPerChannel*, ComputePrecisionWeighted*, AxpyBroadcastInto, MultiplyBroadcastInto, UpdatePrecisionFromError) – is unreachable from FullPCLayer<T>/FullPCNetwork<T>. The "Try*" ones return false, their own interface's well-defined "no fused path here" contract; the conv/precision-weighted ones throw std::logic_error naming this class's scope, rather than shipping an unexercised, unverified implementation of logic nothing in this pass actually calls or tests (the conv family and DiscriminativePCLayer/ ConvPCLayer stay on the non-templated CPUBackend, matching the plan's explicit non-goals).
