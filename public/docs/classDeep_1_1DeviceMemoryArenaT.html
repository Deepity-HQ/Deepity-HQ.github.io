Detailed Description

template<typename T, typename AccumT = T>
class Deep::DeviceMemoryArenaT< T, AccumT >

A 64-byte-aligned bump-pointer allocator over a single contiguous block of device memory, obtained via a supplied IComputeBackendT<T, AccumT> (expected to be a CUDABackend/ CUDABackendT in practice, though this class itself doesn't hard-require that specific type).

Template Parameters
TElement type this arena allocates, matching the backend's own T. DeviceMemoryArena (see the alias below) is DeviceMemoryArenaT<float, float>, bit-for-bit identical to this class before it was templated.
AccumTMatches the backend's own AccumT (only used here to name the exact IComputeBackendT<T, AccumT> this arena's backend pointer must be); defaults to T, as in IComputeBackendT itself.

Allocates a single 64-byte-aligned device buffer large enough to hold total_elements elements of T, rounded up to the nearest 64-byte boundary.

Parameters
backendThe backend to allocate from (and later free through). Must outlive this DeviceMemoryArenaT. Passing a CPUBackend here would allocate host memory under a class named "device", that's a caller contract, not something this class checks at runtime, mirroring Tensor's own backend/device pairing contract.
total_elementsTotal number of elements this arena can hand out across all future Allocate() calls combined.
Exceptions
std::bad_allocif the underlying allocation fails.

Allocates a 64-byte aligned chunk of elements from the arena.

Parameters
num_elementsNumber of elements to allocate from the arena. The actual reservation is rounded up to the nearest 64-byte boundary, matching MemoryArenaT's own guarantee.
Returns
Pointer to the start of the allocated chunk, valid for the lifetime of this DeviceMemoryArenaT. 64-byte aligned.
Exceptions
std::runtime_errorif the requested allocation would exceed the arena's total capacity.
Warning
Individual chunks are never freed independently; the entire arena is released at once in the destructor.
