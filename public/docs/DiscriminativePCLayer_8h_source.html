451/*
452 * MHSA USING PCNs:
453 * In a standard Transformer, Multi-Head Self-Attention (MHSA) computes Queries, Keys,
454 * and Values in a rigid, one-shot forward pass to route token context. If implemented
455 * using a PCN, the attention scores and context vectors would become dynamic latent
456 * states (z). When a sequence is input, the attention routing wouldn't be calculated
457 * instantly; instead, it would iteratively settle over artificial time. The network
458 * would adjust its attention states to minimize the prediction error between the
459 * bottom-up token data and the top-down expectations from higher layers. The Q, K,
460 * and V projection matrices would serve as the local weights (W) for this mechanism,
461 * and would be updated entirely in parallel via local Hebbian rules once the attention
462 * routing reached its minimum-energy equilibrium.
463 */
