Detailed Description

Templated counterpart to FullPCLayer, over a storage type T (the layer's own beliefs/errors/weights/activations) and an accumulator type AccumT (the Adam/AdamW optimizer's gradient/ moment state, always at least as wide as T – see IComputeBackendT<T, AccumT>'s own doc comment). Produced by mechanically retyping FullPCLayer's own float members/parameters to T/AccumT, NOT a reimplementation – every method here must stay line-for-line equivalent to FullPCLayer's own method bodies, so that FullPCLayerT<float, float> reproduces FullPCLayer's output bit-exactly (the quantization plan's verification gate #1).

Deliberately does NOT inherit from Layer: Layer's virtual interface (GetBeliefs() etc.) is fixed at float*, which only FullPCLayerT<float, ...> could ever satisfy. Nothing in this pass needs a FullPCLayerT<T> to be used polymorphically as a Layer*, so this is a free-standing class template instead (the same position FullPCNetwork already has). Every OTHER layer (SimplePCLayer, DirectKPPCLayer, GaussSeidelPCLayer, the conv family) is unaffected and keeps deriving from Layer exactly as before.
