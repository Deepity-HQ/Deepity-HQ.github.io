 		ConvPCNetwork.h
 Network-level wrapper for ConvPCLayer, device-aware (DeviceType constructor parameter, backend member, cpuArena/gpuArena split in Compile()).
 		DirectKPPCNetwork.h
 Orchestrates DirectKPPCLayer's Direct Kolen-Pollack predictive coding (DKP-PC) phases in the correct order, the ORDER of the phases across layers is what makes this DKP-PC rather than plain PC.
 		DiscriminativePCNetwork.h
 Network-level wrapper for DiscriminativePCLayer, the original precision-weighted PC model. Device-aware (DeviceType constructor parameter, backend member, cpuArena/gpuArena split), with auto-batch- size detection (see autoSize below).
 		FullConvPCNetwork.h
 Convolutional analog of FullPCNetwork – see FullConvPCLayer.h for the activation-placement convention this class's math follows (conv activates mu directly, unlike the dense layer's raw-mu/ activated-zF split).
 		FullPCNetwork.h
 Orchestrates FullPCLayer's phases, matching DirectKPPCNetwork's four-phase DKP-PC structure (see that class's docs for the phase breakdown and citation), plus network-level toggles for muPC scaling and residual connections, both OFF by default, so a plain FullPCNetwork reproduces DirectKPPCNetwork exactly (FullPCLayer with a=1.0, useResidual=false is bit-identical to DirectKPPCLayer).
 		FullPCNetworkT.h
 Templated counterpart to FullPCNetwork, over the same T (storage) / AccumT (optimizer accumulator) pair as FullPCLayerT – see that class's own doc comment. Produced by mechanically retyping FullPCNetwork's own float members/parameters to T/AccumT, NOT a reimplementation: every method here must stay line-for-line equivalent to FullPCNetwork's own method bodies, so that FullPCNetworkT<float, float> reproduces FullPCNetwork bit-exactly.
 		GaussSeidelPCNetwork.h
 Orchestrates GaussSeidelPCLayer's three-phase settling step in the correct order. The layer class alone cannot produce genuine Gauss-Seidel dynamics; the sweep order across layers is what makes it Gauss-Seidel rather than Jacobi, and that only exists at this level. Device-aware (DeviceType constructor parameter, backend member, cpuArena/gpuArena split in Compile()).
 		SimpleConvPCNetwork.h
 Convolutional counterpart to SimplePCNetwork, device-aware (DeviceType constructor parameter, backend member, cpuArena/gpuArena split in Compile()).
 		SimplePCNetwork.h
 Network wrapper for SimplePCLayer, mirroring DiscriminativePCNetwork (minus precision/UpdatePrecision()).
