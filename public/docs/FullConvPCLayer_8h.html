Detailed Description

Convolutional analog of FullPCLayer: every PC variant this codebase knows about, each independently toggleable, off by default so plain defaults reproduce SimpleConvPCLayer exactly (NOT the precision-weighted ConvPCLayer – FullPCLayer's own dense lineage is DirectKPPCLayer, which has no precision-weighting either).

Conv layers use a DIFFERENT activation-placement convention than FullPCLayer: dense keeps mu raw/linear and activates z into a separate zF used as the GEMM input; here (matching ConvPCLayer/SimpleConvPCLayer exactly) the activation is applied directly to mu in ComputeMuOnly(). This means UpdateWeights() and ComputeAdjoint() both rely on mu holding phi'(mu) (not phi(raw_mu)) by the time they run – see UpdateState()/ComputeAdjoint()'s own docs.
