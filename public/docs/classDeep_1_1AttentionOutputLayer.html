Detailed Description

Attention-output node: mu[b,i,:] = sum_j attnZ[b,i,j] * V[b,j,:], settled via the ordinary Gaussian energy.

void Deep::AttentionOutputLayer::UpdateState ( float ir,

Settles z one Euler step: z += ir * (eAbove - e) if there's a real layer above (eAbove non-null), else plain z += -ir * e – same shape as FullPCLayer::UpdateState()'s two branches. v1 has no layer above this one (it's the top of the attention block), so eAbove is always nullptr for now.
