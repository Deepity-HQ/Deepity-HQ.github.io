 Same operation as MatMul(), but writes into an AccumT* buffer instead of T* – for a layer's own Adam/AdamW gradient computation (grad_W, grad_Psi, ...), which must land in the wider AccumT accumulator, not get rounded down to storage precision T mid-computation (exactly the gap this method closes: MatMul() itself can only ever write a T* C, so it alone can't produce a loss-free gradient when T is a lossy storage format with AccumT != T, e.g. Fp4E2M1Value). virtual void MatMulAccumMixed (bool transA, bool transB, int M, int N, int K, AccumT alpha, const AccumT *A, int lda, const T *B, int ldb, AccumT beta, AccumT *C, int ldc) noexcept=0
 Same operation as MatMulAccum(), but A is already AccumT* – for a layer's transient settling/gradient scratch (e.g. the activation-derivative-weighted error signal that feeds both UpdateState()'s feedback GEMM and UpdateWeights()'s gradient GEMM), which must never round-trip through storage precision T even transiently: for a lossy T (e.g. Fp4E2M1Value), an activation derivative's natural range commonly falls entirely below T's coarsest resolution (sigmoid's derivative maxes out at 0.25, below Fp4E2M1Value's smallest nonzero magnitude of 0.5), so writing it into a T* buffer even once rounds it to exactly zero and kills the gradient outright – this is that fix. Only B (the real, stored parameter, e.g. W) decodes from T; A is used as-is.
virtual void SetAllowTF32 (bool allow) noexcept=0
 Whether MatMul() may use TF32 (10 mantissa bits, ~1e-3 relative error per GEMM) instead of full FP32 on tensor cores – CUDABackend only; a no-op on CPUBackend, which has no such distinction. Defaults to allowed, matching PyTorch's own default, since every conv in this library lowers to im2col+MatMul and would otherwise run at a fraction of the GPU's peak throughput. Turn off before a finite-difference gradient check: TF32's error is large enough to either fail those checks for no real reason, or tempt loosening their tolerance until it stops catching real bugs.

virtual bool TryFusedFeedbackUpdate (ActivationType dType, int batchSize, int size, int nextSize, const T *eAbove, const T *W, T *z, const T *e, AccumT ir, T *scratch, T *derivScratch) noexcept=0
 Fuses SimplePCLayer::UpdateState()'s feedback GEMM directly into its own elementwise state update – the GEMM's output is never separately read back and re-walked by its own pass: feedback = e_above @ W (M=batchSize,N=size,K=nextSize) z += ir * (f'(z) * feedback - e) Primary mechanism (CPUBackend, DEEPITY_USE_ONEDNN): a dnnl::matmul primitive with the elementwise update welded on as post-ops (binary_mul/binary_add), evaluated in registers on each output tile right as oneDNN's own GEMM microkernel produces it – same kernel, same thread pool as every other matmul in this file, just with the epilogue attached. virtual AccumT ComputeSoftmaxCrossEntropyErrorAndEnergy (T *e, const T *z, const T *mu, size_t batchSize, size_t nextSize, AccumT *rowEnergies) noexcept=0
 Softmax cross-entropy variant of ComputeErrorAndEnergy, for the terminal layer only. Detailed Description

template<typename T, typename AccumT = T>
class Deep::IComputeBackendT< T, AccumT >

Device-agnostic compute backend interface: every numerical primitive a layer/network needs, implemented once each by CPUBackend (SIMD/BLAS) and CUDABackend (kernels/cuBLAS/CUTLASS), so layer code never branches on device directly.

Template Parameters
TElement type for this backend's data buffers (activations, weights, errors, biases, ...). IComputeBackend (see the alias below) is IComputeBackendT<float, float>, bit-for-bit identical to this interface before it was templated – every existing caller (SimplePCLayer, DirectKPPCLayer, GaussSeidelPCLayer, the conv family) keeps using that exact spelling, unchanged.
AccumTWider type used for optimizer accumulator state (AdamStep/AdamWStep's grad/m/v/lr) and for scalar hyperparameters/reductions (alpha, beta, eps, ir, Sum()'s return, ...) – "accumulate wider than you store/compute the forward pass at," so a sub-8-bit T never gets Adam-stepped in its own low-precision representation. Defaults to T for every existing (non-templated) caller, where it's simply unused distinction (AccumT=T=float there); FullPCLayer<T, AccumT=double> is the only place this is ever spelled as something other than T.
