Detailed Description

Causal attention-weights node: mu[b,i,j] = (Q[b,i,:] . K[b,j,:]) / sqrt(headDim), causally masked, settled via the categorical/KL energy against its own belief z (the attention weights themselves).

◆ UpdateState()

void Deep::AttentionScoresLayer::UpdateState ( float ir,
const float * eAbove,
const float * vBeliefs )
noexcept

Settles z one Euler step: z += ir * (feedback - e), where feedback is the top-down signal from AttentionOutputLayer above (feedback[b,i,j] = sum_d e_above[b,i,d] * V[b,j,d], i.e. e_above projected through V^T – the Jacobian of mu_output = attnZ @ V w.r.t. attnZ, no activation derivative needed since that product is already linear in attnZ). With no layer above (vBeliefs == nullptr), reduces to plain z += -ir * e.

Parameters
irInference rate (Euler step size).
eAboveAttentionOutputLayer's error buffer, shape [batchSize, seqLen, headDim], or nullptr if there's no layer above.
vBeliefsV layer's belief buffer, same shape as eAbove, or nullptr if there's no layer above.
